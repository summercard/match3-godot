# MagnetJet（极速磁链下载）

一个单任务、中文界面的磁力链接下载器。粘贴磁力链接，选择文件夹，点击开始即可使用。

## 功能

- 粘贴磁力链接并选择下载文件夹
- 实时进度条、下载/上传速度、已下载大小、节点数量
- 开始、暂停、继续、新建任务与打开文件夹
- 关闭软件时尽力保存下载状态；下次启动时会恢复未完成任务，并保持暂停，等待你点击继续
- 启用 DHT、PEX、LSD、uTP、UPnP / NAT-PMP
- 使用固定的高位监听端口，帮助已知节点在后续启动时重新连接
- 完成后自动暂停，避免持续占用上传带宽

## 最快的使用方式

1. 使用 Windows 10/11 64 位与 Python 3.10、3.11 或 3.12。
2. 双击 `run_windows.bat`。
3. 在软件中粘贴以 `magnet:?xt=urn:btih:` 开头的链接。
4. 点击“选择文件夹…”，再点击“开始下载”。

首次启动会创建 `.venv` 并安装依赖，之后直接双击同一个 `run_windows.bat` 即可。

## 生成独立 EXE

双击 `build_windows.bat`。完成后打开：

```text
dist\MagnetJet\MagnetJet.exe
```

该版本使用 `--onedir` 打包：请保留 `dist\MagnetJet` 整个文件夹，不要只移动其中的 EXE。

## 速度说明

软件已打开常见的节点发现与端口映射机制，但没有任何客户端能保证“全速”。最终速度仍取决于资源的可用做种者、对方上传带宽、你的网络、路由器是否允许入站连接，以及本地磁盘写入能力。

- 磁力链接开始时会先显示“获取元数据”，这是正常阶段。
- 想提升连接成功率，可在路由器中为软件显示的监听端口配置 TCP/UDP 端口转发；UPnP/NAT-PMP 能用时会自动尝试。
- 将下载目录放在 SSD 通常更适合高并发的小文件写入。
- 本软件默认只处理一个任务，避免多个任务抢占连接与磁盘带宽。
