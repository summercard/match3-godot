# 签到界面资产代入表

更新时间：2026-05-20

## 接入说明

本轮处理 `SceneSignIn` 每日签到界面。流程按项目美术管线执行：读取 `美术开发/概念图/14_每日签到_sign_in.png` 作为布局和风格方向 -> 使用 image-2 生成 UI 与奖励两张元素提取源 -> 本地脚本拆分为透明 PNG -> 导入 `assets/images/sign_in/` -> 将 Godot 场景从色块/emoji 绘制改为 Canvas 正式资产绘制。

没有直接裁切概念图作为运行资产。

## 功能保留

| 功能 | 状态 |
|---|---|
| 返回大厅 | 保留，点击左上返回按钮发出 `back_pressed` |
| 今日可签到判断 | 保留，读取 `SaveManager.can_sign_in_today()` |
| 发放奖励 | 保留，调用 `SaveManager.do_sign_in()` 发金币和经验 |
| 成就统计 | 保留，更新 `maxConsecutiveSignIn` 和 `totalSignInDays` |
| 成功反馈 | 已升级为粒子、飘字、星光和成功提示 |

## 质量约束

| 风险 | 处理方式 |
|---|---|
| UI 重叠 | 7 日卡、月奖励面板、按钮使用固定 Rect，文字限制宽度 |
| 图标拉伸 | 奖励、宝箱、吉祥物统一使用 contain 绘制 |
| 点击区错位 | 返回按钮和领取按钮点击区与视觉 Rect 同源 |
| 重复资产 | 金币/EXP 等本可复用，但签到卡展示规格不同，本轮保留签到专属大图标；后续若通用奖励大图标体系稳定再抽到公共目录 |
