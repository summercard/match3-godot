## 冲突/复用结论

| 分类 | image-2 提取内容 | 结论 |
|---|---|---|
| 怪物 | 花 Boss、火/水/草初始怪候选 | 不新增运行资源，继续复用 `assets/images/battle/monsters/` |
| 怪物 | 雷狐、暗猫候选 | 暂登记为候选，待 MonsterDB ID 明确后再进入通用怪物目录 |
| 奖励 | 金币、EXP、捕获药水/球、火草宝石 | 不新增运行资源，运行时代码定向到 stage/battle 通用图标 |
| 星级 | 大金星、灰星 | 结果页展示尺寸和光效明显不同，作为 `assets/images/result/` 专属资产 |
| UI | 胜负横幅、奖励面板、队伍经验面板、按钮 | 结果页专属，已放入 `assets/images/result/` |
| 特效 | 胜利爆光、彩纸、捕获环、升级光条 | 结果页专属，已放入 `assets/images/result/` |
