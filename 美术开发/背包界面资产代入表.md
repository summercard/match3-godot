# 背包界面资产代入表

更新时间：2026-05-27

## 制作口径

本次处理 `SceneInventory` 背包界面。确认已有概念图：`美术开发/概念图/11_背包_inventory.png`。流程为：读取概念图作为版式和风格方向 -> 使用 image-2 生成背包 UI 元素提取源 -> 从 image-2 提取源拆分正式资产 -> 复制必要 UI 到 `assets/images/inventory/` -> 道具/进化石图标沉淀为 `assets/images/items/` 供商店和背包共用 -> Godot Canvas 代码代入。

本轮没有直接裁切 `11_背包_inventory.png` 作为运行资产。

## 路径

| 类型 | 路径 | 说明 |
|---|---|---|
| 概念图 | `美术开发/概念图/11_背包_inventory.png` | 背包布局、分类和详情面板参考 |
| image-2 提取源 | `美术开发/元素提取/inventory/inventory_ui_image2_sheet.png` | 背包 UI 元素提取源 |
| 正式拆分 | `美术开发/正式拆分/inventory/ui/` | 背包 UI 透明 PNG |
| 运行 UI | `assets/images/inventory/` | Godot 背包专属运行资源 |
| 通用道具 | `assets/images/items/` | 商店和背包共享的道具/进化石图标 |
| 代码入口 | `src/ui/scenes/inventory.tscn` + `src/ui/scene/scene_inventory_gui.gd` | GUI 节点承载资产，脚本只刷新数据与绑定功能；旧 `scene_inventory.gd` 作为数据/使用逻辑基类保留 |

## 代码代入

| 功能 | 代入方式 |
|---|---|
| 概念图版式 | 改为 5 列道具格、四分类标签、底部详情面板，贴近 `11_背包_inventory.png` |
| 分类 | `全部 / 道具 / 材料 / 宝石`，通过 `_matches_tab()` 过滤 |
| 道具选择 | 点击格子更新 `_selected_item`，详情面板即时刷新 |
| 使用道具 | 使用按钮继续调用 `_use_item()`，保留经验、金币、捕获、战斗、进化类提示逻辑 |
| 翻页 | 背包格区域取消拖动滚动，改为 15 格/页并使用上一页/下一页按钮 |
| 复用 | 商店与背包共用 `assets/images/items/`，商店代码路径已同步更新 |
