# 成就界面资产代入表

更新时间：2026-05-27

## 制作口径

本次处理 `SceneAchievement` 成就界面。确认已有概念图：`美术开发/概念图/12_成就_achievement.png`。流程为：读取概念图作为版式和风格方向 -> 使用 image-2 生成成就 UI/徽章元素提取源 -> 从 image-2 提取源拆分正式资产 -> 复制成就专属资产到 `assets/images/achievement/` -> 奖励金币和奖励槽优先复用现有通用资产 -> Godot Canvas 代码代入。

本轮没有直接裁切 `12_成就_achievement.png` 作为运行资产。

## 质量约束

| 风险 | 处理方式 |
|---|---|
| UI 重叠 | 成就页改为单一 Canvas 绘制，卡片、按钮、进度条和点击区全部由固定 Rect 计算 |
| 文字不齐/溢出 | 成就名和描述使用固定宽度，长文本通过 `_ellipsize()` 截断 |
| 图标拉伸 | 徽章、奖杯、奖励图标全部通过 `_draw_texture_contain()` 等比绘制 |
| 点击区错位 | 领取按钮点击区由 `_get_claim_rect()` 和绘制共用同一 Rect |
| 滚动遮挡 | 保持 Canvas 版本；列表先绘制，随后重绘顶部固定 UI，并且只绘制完整落在 `LIST_TOP` 到 `LIST_BOTTOM` 内的卡片，避免下滑时覆盖分类/总览区 |

## 代码代入

| 功能 | 代入方式 |
|---|---|
| 概念图版式 | 顶部返回/标题、奖杯总览、五分类标签、卡片列表按概念图结构重排 |
| 分类筛选 | 保留 `all / battle / collect / numeric / continuous` 五类数据筛选 |
| 成就进度 | 从 `SaveManager.load_achievements()` 和派生统计读取进度，显示进度条和进度文本 |
| 领取奖励 | 已解锁未领取成就点击领取按钮，发放金币并保存 `claimedIds` |
| 锁定状态 | 未解锁卡片灰罩、锁图标、禁用按钮 |
| 复用策略 | 金币复用 main，奖励槽复用 inventory；成就徽章和成就框架留在 achievement 专属目录 |
