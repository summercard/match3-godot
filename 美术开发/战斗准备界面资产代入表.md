## 冲突/复用结论

| 分类 | image-2 提取内容 | 结论 |
|---|---|---|
| 怪物 | 花叶兽、草苗儿、水系幼兽等与已有通用怪物重合 | 不新增运行资源，继续复用 `assets/images/battle/monsters/` |
| 怪物 | 石头人、火焰野猪、火狐 | 暂登记为候选，后续需要绑定 MonsterDB ID 后再进入通用怪物目录 |
| 宝石 | 火/水/草/雷/光宝石 | 不新增运行资源，继续复用 `assets/images/stage/icon_gem_*` 和 `assets/images/battle/gems/*` |
| 奖励 | 金币、EXP、捕获球 | 不新增一套视觉，运行时复用已有 stage 图标 |
| UI | 顶栏、卡框、战力面板、开始按钮 | 战斗准备页专属，已放入 `assets/images/battle_prepare/` |

`assets/images/battle_prepare/` 只保留战斗准备专属 UI 和背景；怪物、宝石、奖励、返回箭头等通用内容由代码定向到已有通用目录。
