# 战斗界面资产代入表

## 接入说明

本次处理 `SceneBattle` 战斗界面。资产流程为：战斗概念图参考 -> image-2 补充提取/重绘 -> 透明化与分类 -> 复制到游戏工程 `assets/images/battle` -> 在 `js/ui/sceneBattle.js` 中加载并绘制。

本次代入优先覆盖战斗画面核心视觉：背景、怪物立绘、棋盘宝石、锁定宝石、石块障碍。旧的 emoji/色块绘制保留为资源未加载时的兜底。

## 代码接入点

| 方法/常量 | 作用 |
| --- | --- |
| `BATTLE_ASSETS` | 战斗美术资产路径表 |
| `GEM_ASSET_KEYS` | 棋盘宝石类型到图片资产的映射 |
| `_loadBattleArtAssets()` | 使用 `wx.createImage()` 加载战斗资产 |
| `_getMonsterAssetKey()` | 怪物/敌人ID和元素到立绘资产的映射 |
| `_drawGemAsset()` | 棋盘宝石PNG绘制，失败时回退旧emoji绘制 |
| `_renderEnemies()` | 敌方信息卡加入Boss/敌人立绘 |
| `_renderTeam()` | 我方状态卡加入怪物立绘 |
| `_renderLockedGems()` | 锁定宝石改用透明PNG |
| `_renderObstacles()` | 石块障碍改用透明PNG |
