## 设计判断

| 方向 | 处理 |
| --- | --- |
| 与通用虚空底图区分 | 通用 `void` 底图仍是暗紫草地换色；第七章改成悬浮断桥、空间裂隙和深渊遗迹 |
| 关卡题材进入场景 | 虚空入口用下层传送门表达，噬魂巢穴与虚空裂隙用巢状晶核、裂隙瀑流和悬浮岛表达，暗蚀深渊用断桥坠落感表达 |
| Boss 区 | 概念图给出虚空巨龙圣所方向，运行背景保留空终点圆台，由现有虚空 Boss 运行立绘覆盖 |

## 运行检查

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 第七章专属底图加载 | 通过 | 运行截图显示虚空断桥、裂隙圆台和悬浮遗迹，不再回落到通用草地图 |

| 运行尺寸链路 | 通过 | 抓图日志为逻辑视口 `375x667`、窗口 `750x1334`、framebuffer `750x1334` |
