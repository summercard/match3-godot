## 设计判断

| 方向 | 处理 |
| --- | --- |
| 与通用冰属性底图区分 | 通用 `ice` 底图仍是草原河谷调色；第六章改成极地王城、冰晶峡谷和极光王座 |
| 关卡题材进入场景 | 寒冰入口用下层王城门庭表达，霜狼巢穴与极地冰原用雪林裂谷表达，冰晶洞穴用发光晶洞和桥梁表达 |
| Boss 区 | 概念图给出冰霜巨龙王座方向，运行背景保留空王座平台，由现有冰属性 Boss 运行立绘覆盖 |

## 运行检查

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 第六章专属底图加载 | 通过 | 运行截图显示极地王城平台、冰晶裂谷和极光天幕，不再回落到通用草地图 |
| 同冰属性章节隔离 | 通过 | `chapter_6` 使用章节 override，通用 `stage_map_bg_ice.png` 保留给其他冰属性章节 |
| 通用资产复用 | 通过 | 节点、精英水晶、路径点、奖励栏、宝石、箭头和冰属性 Boss 立绘继续复用 |
| 资源导入 | 通过 | Godot import 已生成第六章概念、提取源、正式背景和运行背景导入链路 |
| 运行尺寸链路 | 通过 | 抓图日志为逻辑视口 `375x667`、窗口 `750x1334`、framebuffer `750x1334` |
| 节点与奖励栏同屏 | 通过 | 第六章 5 个关卡节点、Boss 节点和底部奖励栏均在运行截图内 |
