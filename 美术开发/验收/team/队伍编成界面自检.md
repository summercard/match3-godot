## 自检结果

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 设计尺寸口径 | 通过 | 抓图日志为逻辑视口 `375x667`、运行窗口 `750x1334` |
| 概念图分区 | 通过 | 顶部标题、三张队伍卡、战力/队长技横条、下方精灵选择区、底部操作按钮已分区 |
| 底部精灵翻页 | 通过 | 每页 8 只；demo 名单验证 `1/2` 与 `2/2` 两页 |
| 多页按钮排布 | 通过 | 左右箭头使用 `46x44` 命中区，页码、页点不压精灵卡和保存按钮 |
| 图标等比绘制 | 通过 | 精灵头像、列表属性徽章、翻页箭头使用 contain 绘制，卡框内建图标不再重复覆盖 |
| 三槽功能保留 | 通过 | 队长、成员 1、成员 2 的命中区仍沿槽位矩形工作 |
| 移动端可读与可点 | 通过 | 标题、卡片、工具栏、主操作文字已放大；主要按钮命中高度均不低于 `44px` |
| 工具交互闭环 | 通过 | 问号说明、属性筛选、等级/战力/稀有度排序均可操作 |
| 无效按钮清理 | 通过 | 当前不存在完整业务闭环的“分解”入口不再展示 |
| 重复图层清理 | 通过 | 队伍槽、战力栏与队长技栏均只保留底图的一套图标；列表选中仅一枚勾，星级仅展示真实值 |
| 横条比例与卡片底纹 | 通过 | 战力/队长技横条仅伸缩中部底纹，边框与徽章不拉伸；列表使用原纹理补片替代实色遮罩 |
| 队伍转场体验 | 通过 | 纹理提前预热；进出队伍页切换为 `0.11s` 浅遮罩，无完整黑屏停顿 |
| 怪物素材一致性 | 待后续 | 部分后续编号精灵沿用现有通用头像，个别源图仍带提取瑕疵；本轮未重复生成怪物资产 |
