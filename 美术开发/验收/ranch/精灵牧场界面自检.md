## 编辑入口

| 用途 | 文件或节点 |
|---|---|
| Godot 场景文件 | `src/ui/scenes/ranch_hub.tscn` |
| 牧场主页节点 | `Pages/RanchPage` |
| 怪物课堂节点 | `Pages/ClassroomPage` |
| 社交庭院节点 | `Pages/SocialPage` |
| 动态数据与按钮绑定 | `src/ui/scene/scene_ranch_gui.gd` |

`main.gd` 的 `PACKED_SCENE_MAP["ranch"]` 已直接加载该 `.tscn`，与大厅 `main_lobby.tscn` 使用同一种编辑方式。按钮美术采用可缩放 `TextureRect` 作为子节点、按钮作为透明热区，手调尺寸不会再被源图大小撑开。

## 人工复核

| 检查项 | 结果 |
|---|---|
| 牧场背景与台座 | 直接使用背景内原生五座石台；精灵立绘落点已下调贴合承重面，并已消除叠画造成的双层台座 |
| 美术资产化 | 主页名单区复用课堂/社交同款木框叶饰并以九宫格适配浅高度，右边缘完整；课堂详情/名单、社交场所/槽位/关系条/结果弹窗均为正式位图 |
| 精灵图像 | 主页、名单、课堂和社交位均按比例 contain 显示，无横向或纵向拉伸 |
| 收益区 | 删除独立收益底板和“可放置精灵”标题；奖励图标与金色收获按钮浮置在名单框上方，按钮与收获逻辑已绑定 |
| 手机点击 | 返回、收获、三底部导航、课堂进化、社交换场/动作按钮均保持至少 44 px 高 |
| 可读性 | 小字已精简；课堂详情、进化按钮、社交关系和结果文案无压边或互相覆盖；课堂属性去除系统 emoji |
| 特效一致性 | 放置反馈改为牧场叶光资产，不以系统字符气泡充当美术内容 |
| GUI 可编辑性 | 三页可见布局均存在于 `.tscn` 场景树；运行界面不再依赖 `_draw()` 拼制面板、按钮或卡片 |
