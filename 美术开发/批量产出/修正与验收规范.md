# 修正与验收规范

## 修正优先级

| 优先级 | 问题 | 处理方式 |
| --- | --- | --- |
| P0 | 资产侵权、明显像现成IP、文字不可控 | 立即重做 |
| P1 | 玩法识别失败，如宝石颜色混淆、按钮看不出状态 | 重绘或统一色彩/轮廓 |
| P2 | 风格不统一，如卡片圆角、描边、光效厚度不一致 | 进入统一化修正 |
| P3 | 装饰细节不足、局部精修 | 放入后续 polish |

## 模块验收标准

| 模块 | 验收重点 |
| --- | --- |
| 启动页 | 一眼能看到游戏主题、初始怪物、进入按钮；标题不遮挡核心角色 |
| 主界面 | 入口优先级清楚，队伍、冒险、图鉴、商店不混淆 |
| 关卡地图 | 普通/精英/宝箱/Boss节点明显不同，星级和奖励易读 |
| 三消战斗 | 8x8棋盘清楚，五元素宝石不混色，敌我状态和回合信息清楚 |
| 图鉴 | 未解锁、已收集、详情、进化入口状态明确 |
| 队伍/进化 | 队长与成员差异明确，战力与队长技能突出，进化前后差异足够 |

## 当前拆分资产的局限

- 当前 PNG 是从整屏概念图裁切，部分资产带背景或文字，不能直接等同正式透明素材。
- 宝石样例可能包含棋盘格背景，正式版应重新输出透明宝石。
- 怪物目前多为组合裁切，正式版需要按怪物 ID 单独输出头像、立绘、战斗姿态。
- UI 面板当前是整块图，正式版应拆为九宫格底、描边、图标、文字层。

## 迭代方法

1. 在 `美术开发/概念图` 替换或新增概念图。
2. 修改 `美术开发/批量产出/split_concept_assets.py` 中对应模块的裁切坐标。
3. 执行：

```bash
python3 美术开发/批量产出/split_concept_assets.py
```

4. 检查 `美术开发/资产拆分/*_contact_sheet.png`。
5. 对照 `美术开发/美术资产拆分与游戏对照表.md` 确认每个资产都有代码入口和用途。
