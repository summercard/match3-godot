# 大厅界面资产代入表

## 接入说明

本次处理 `SceneMain` 大厅/主菜单界面，也就是包含「开始冒险、队伍编成、怪物图鉴、每日签到、商店、背包、牧场、成就、设置」入口的界面。

资产流程为：大厅背景概念生成 -> image-2 风格图标/框体 sheet -> 色键透明化 -> 独立元素拆分 -> 复制到 `assets/images/main` -> 在 `js/ui/sceneMain.js` 中加载并绘制。
