# 大厅界面资产代入表

更新时间：2026-05-19

## 制作口径

本次重制 `SceneMain` 大厅/主菜单界面，使用新概念图：`美术开发/概念图/大厅.png`。流程为：读取新概念图作为布局和风格方向 -> 使用 image-2 生成无 UI 的大厅背景与独立 UI/图标提取源 -> 拆分正式资产 -> 复制运行资源到 `assets/images/main/` -> 按新概念图重排 4 个场景入口和 5 个底部入口。

本轮没有直接裁切 `大厅.png` 作为运行资产。

## 质量约束

| 风险 | 处理方式 |
|---|---|
| UI 重叠 | 4 个场景入口和 5 个底部入口使用固定 Rect，按钮绘制和点击区域同源 |
| 图标拉伸 | 头像、入口图标、底部导航图标、货币图标统一使用等比 contain 绘制 |
| 文字不齐 | 顶部昵称、货币、按钮文字使用固定宽度，长昵称截断 |
| 入口错位 | 入口坐标按新概念图：传送门、编队屋、牧场、商店、底部五栏 |
| 旧布局残留 | 旧 2x2 卡片布局已替换为场景建筑入口布局 |
