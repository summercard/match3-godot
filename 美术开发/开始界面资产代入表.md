## 代码接入点

| 方法 | 作用 |
| --- | --- |
| `_loadArtAssets()` | 使用 `wx.createImage()` 加载开始页全部美术资产 |
| `_renderArtStartScreen()` | 资产加载成功后绘制新版开始界面 |
| `_drawStartMonster()` | 绘制三只初始怪物并加入轻微浮动 |
| `_drawStartGem()` | 绘制五元素宝石并加入轻微呼吸 |
| `_drawGlowButton()` | 优先绘制按钮图片资产，再叠加文字和按压态 |
| `_drawStartHint()` | 绘制提示旗帜底板和点击提示文字 |
| `_drawStartVersion()` | 绘制版本号铭牌和版本文字 |
| `_getEnterButtonRect()` | 统一视觉按钮和点击热区 |
