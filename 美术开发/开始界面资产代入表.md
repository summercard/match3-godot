# 开始界面资产代入表

更新时间：2026-05-31

## 接入说明

本次只处理 `SceneStart` 开始/欢迎界面。资产流程为：概念图参考 -> image-2 元素提取/重绘 -> 透明化/分类 -> 复制到游戏工程 `assets/images/start` -> 在 Godot UI 场景 `src/ui/scenes/start_screen.tscn` 中按节点代入。

旧的整屏裁切资产不参与本次接入。

欢迎页已迁移为可编辑 UI 场景模式。静态视觉不再由 `_draw()` 每帧手绘；脚本仅负责轻动画、单击进入和新手教程分流。

## 代码接入点

| 文件或方法 | 作用 |
| --- | --- |
| `main.gd` `PACKED_SCENE_MAP.start` | 将欢迎页从脚本绘制模式切换到 Godot PackedScene |
| `src/ui/scenes/start_screen.tscn` | 管理全部静态视觉节点、尺寸、层级和按钮热区 |
| `scene_start.gd` `_animate_monsters()` | 为三只初始怪物加入轻微浮动 |
| `scene_start.gd` `_animate_gems()` | 为五元素宝石加入错相浮动和呼吸 |
| `scene_start.gd` `_animate_button()` | 管理开始按钮光晕和底部提示呼吸 |
| `scene_start.gd` `_on_start_button_down()` | 按下按钮即进入，不等待长按或松手 |
| `scene_start.gd` `_get_entry_scene()` | 保留新手教程与大厅分流 |
| `src/ui/components/start_particle_layer.gd` | 独立管理背景星点装饰层 |
