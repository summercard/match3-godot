# 关卡选择界面资产代入表

## 接入说明

本次处理 `SceneStageSelect` 关卡选择界面，目标参考用户提供的概念图：顶部章节条、地图路径节点、BOSS 大节点、底部通关奖励栏。

资产流程为：概念图参考 -> image-2 概念产出/元素提取 -> 分类拆分 -> 复用冲突检查 -> 复制到 `assets/images/stage` -> 在 `src/ui/scene/scene_stage_select.gd` 中按地图节点布局绘制。

## 代码接入点

| 方法 | 作用 |
| --- | --- |
| `CHAPTER_THEME_BACKGROUNDS` | 按 `chapter.element` 切换章节地图背景 |
| `CHAPTER_BACKGROUND_OVERRIDES` | 章节专属背景优先映射，避免同元素章节互相覆盖 |
| `MAP_STAGE_POSITION_PRESETS` | 为 5 关章节单独配置 image-2 概念路径点位 |
| `_draw_chapter_header()` | 绘制概念图风格顶部章节条 |
| `_draw_stage_paths()` | 在节点之间绘制路径点 |
| `_draw_stage_card()` | 绘制普通/精英/BOSS 关卡节点 |
| `_draw_reward_panel()` | 绘制底部通关奖励栏 |
| `_draw_sweep_dialog()` | 使用新奖励面板和图标绘制扫荡确认弹窗 |
