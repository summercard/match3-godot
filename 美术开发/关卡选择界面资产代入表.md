# 关卡选择界面资产代入表

## 接入说明

本次处理 `SceneStageSelect` 关卡选择界面，目标参考用户提供的概念图：顶部章节条、地图路径节点、BOSS 大节点、底部通关奖励栏。

资产流程为：概念图参考 -> image-2 风格重绘/元素提取 -> 色键透明化 -> 独立元素拆分 -> 复制到 `assets/images/stage` -> 在 `js/ui/sceneStageSelect.js` 中按地图节点布局绘制。

## 代码接入点

| 方法 | 作用 |
| --- | --- |
| `_loadArtAssets()` | 加载关卡地图全部图片资产 |
| `_buildCards()` | 将章节关卡从列表卡片改为地图节点位置 |
| `_renderChapterHeader()` | 绘制概念图风格顶部章节条 |
| `_renderStagePath()` | 在节点之间绘制路径点 |
| `_renderStageCard()` | 绘制普通/精英/BOSS 关卡节点 |
| `_renderRewardPanel()` | 绘制底部通关奖励栏 |
| `_renderSweepDialog()` | 使用新奖励面板和图标绘制扫荡确认弹窗 |
