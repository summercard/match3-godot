# 商店界面资产代入表

更新时间：2026-05-27

## 接入说明

本次处理 `SceneShop` 商店界面。流程为：读取 `10_商店_shop.png` 概念图作为方向 -> 使用 image-2 生成 UI/背景/魔法师、道具、宝石/进化石三张元素提取源 -> 从 image-2 提取源拆分正式资产 -> 复制必要资产到 `assets/images/shop/` -> 迁移为可编辑 Godot GUI 场景。界面布局按手机端成品化重做为顶部标题/货币条、推荐/道具/宝石分页、9 张商品卡/页、底部入口栏、购买确认弹窗；新手礼包横幅暂时隐藏。

## image-2 元素提取源

| 分类 | 提取源 | 说明 |
|---|---|---|
| UI | `美术开发/元素提取/shop/shop_ui_image2_sheet.png` | 背景、顶栏、返回按钮、货币条、分页、礼包横幅、商品卡、价格条、购买按钮、弹窗、底部栏 |
| 道具 | `美术开发/元素提取/shop/shop_items_image2_sheet.png` | 捕获球、经验药水、HP 药水、金币箱、强化石、召唤券等商品图标 |
| 宝石/进化石 | `美术开发/元素提取/shop/shop_gems_image2_sheet.png` | 火/水/草/雷/光/土/风/暗进化石商品图标 |

说明：当前正式资产由 `美术开发/批量产出/split_shop_image2_assets.py` 从上述 image-2 提取源拆分；未直接裁切 `10_商店_shop.png` 作为运行资产。

## 功能保留

| 功能 | 结果 |
|---|---|
| 返回大厅 | 保留，点击左上返回按钮进入 `main` |
| 商品购买 | 保留，点击商品卡/商品图标直接打开确认弹窗，不再使用独立购买按钮 |
| 货币扣除与入库 | 保留并修正，金币/钻石购买都会保存玩家数据并调用 `add_item()` |
