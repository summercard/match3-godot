# 美术开发交付包

## 目录结构

- `概念图/`：6张模块效果图，已按功能命名。
- `元素提取/image2_source/`：使用 image-2 根据概念图提取/重绘出的纯色抠图源文件。
- `正式拆分/`：按 `monsters`、`gems`、`ui` 分类输出的透明 PNG 资产，这是后续接入游戏的主目录。
- `资产拆分/`：上一版从概念图直接裁切出的参考图块，仅作旧版参考。
- `legacy_concept_crops/`：旧裁切资产归档说明。
- `正式资产导出/`：后续正式可接入资源的建议落位目录。
- `批量产出/`：裁切脚本、批量生成规范和修正方法。
- `专业美术资产拆分对照表.md`：image-2 元素提取后得到的正式拆分对照表。
- `专业美术资产拆分对照表.csv`：正式拆分对照表的表格版本。
- `professional_art_asset_manifest.json`：正式拆分资产的程序 manifest。
- `美术资产拆分与游戏对照表.md` / `美术资产_游戏对照表.csv`：旧版概念裁切对照表，仅作追溯参考。

## 当前交付状态

当前正式资产状态是 `image2_extracted_alpha_v1`：先使用 image-2 根据概念图进行元素提取/重绘，再本地去纯色背景得到透明 PNG，并按怪物、宝石、UI 分类拆分。

旧版 `concept_crop_v1` 只保留为参考，不作为专业拆分资产使用。

## 美术主方向

- 原创 Q 版怪物，不仿现有怪物 IP。
- 像素风启发，但保留高清移动端 UI 质感。
- 深蓝 UI 面板承载信息，亮色元素宝石承担玩法识别。
- 竖屏微信小游戏，优先服务单手操作和 Canvas 渲染效率。
