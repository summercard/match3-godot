# 设置界面资产代入表

更新时间：2026-05-20

## 接入说明

本轮处理 `SceneSettings` 设置界面。根据当前需求，本界面不再新做 image-2 提取与独立拆分，而是直接复用项目里已经完成代入的 UI 元素进行组合：背景、返回按钮、标题条、面板、设置行、分段标签、按钮、通知点和齿轮图标均来自现有运行目录。

本轮没有新增 `assets/images/settings/` 运行资产，避免与成就、背包、商店、主界面已有通用 UI 重复。

## 质量约束

| 风险 | 处理方式 |
|---|---|
| UI 重叠 | 5 个设置项使用固定 `Rect2`，标题、版本栏、底部按钮分区独立 |
| 图标拉伸 | 齿轮与警示点使用 contain 绘制；面板/按钮使用 fit 绘制 |
| 文字不齐 | 标题居中，行标题左对齐，描述文字限制宽度 |
| 点击区错位 | 返回、设置行、分段选项、底部按钮与视觉 Rect 同源 |
| 重复资产 | 不新增 settings 专属 PNG，全部复用现有运行资产 |
