# 怪物牧场界面资产代入表

更新时间：2026-05-18

## 代入结果

| 项目 | 结果 |
|---|---|
| 布局 | 已从旧控件纵排改为概念图式 3+2 放置台，底部两层面板 |
| 槽位 | 支持 5 个牧场槽位；点击槽位选中，点击怪物列表放置/移除 |
| 收益 | 显示单槽放置时间、单槽收益、总收益；点击“收获”仍走原经验结算逻辑 |
| 怪物 | 复用 `MonsterArtDB` 通用怪物立绘；缺图怪物回退 emoji |
| 验证 | Godot import 通过；项目 headless 启动通过；临时脚本实例化、点选、放置、收获路径通过 |

## 后续修正建议

1. 在真实运行窗口对比概念图检查 5 个槽位与背景台座是否需要像素级微调。
2. 牧场当前金币为收益表现层估算值，存档仍只结算 EXP；后续若要金币收益，需要补 SaveManager 字段。
3. 为缺少通用立绘的后续怪物补小头像，否则底部列表会出现 emoji fallback。
