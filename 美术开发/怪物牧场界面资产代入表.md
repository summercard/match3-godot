# 怪物牧场界面资产代入表

更新时间：2026-05-26

本轮处理 `SceneRanch` 怪物牧场界面。2026-05-26 复核发现，仅调整布局仍会令课堂/社交页呈现系统 UI 感；因此追加牧场专属正式位图资产，将可见面板、名单卡、槽位、关系条与结果弹窗全部换为木框叶饰的明亮幻想冒险美术。主页复验又修正了精灵悬空、旧名单底板切边和独立收益底板过重的问题。

## 代入结果

| 项目 | 结果 |
|---|---|
| 布局 | 已按 375 x 667 手机画布重排为 3+2 原生场景石台、无标题精灵列表、浮置收获行与底部导航分区 |
| 槽位 | 支持 5 个牧场槽位；点击槽位选中，点击怪物列表放置/移除 |
| 收益 | 状态条显示放置/专注时间；EXP/金币表现与正式“收获”按钮无底板布置在精灵栏上方；按钮已绑定原经验结算逻辑 |
| 子页 | “怪物课堂”和“社交庭院”已由牧场专属位图面板承载详情、名单、槽位、关系条与结果弹窗，属性文本不再混用系统 emoji |
| 正式资产替换 | 已撤下课堂详情/名单卡/社交框/社交槽位/弹窗的程序描边面板；动态数据只负责在正式空框上绘制内容 |
| 可编辑场景迁移 | `main.gd` 已按大厅方式将 `ranch` 指向 `ranch_hub.tscn`；可见元素均为 `TextureRect`、`NinePatchRect`、`Label` 与透明点击层节点，位置和资产可在 Godot GUI 中直接修改 |
| 怪物 | 复用 `MonsterArtDB` 通用怪物立绘并统一 contain 等比绘制，不复制重复资产、不拉伸头像 |
| 点击 | 返回、收获、导航、进化、换场与社交动作热区高度均不低于 44 设计像素 |
| 验证 | 主页二次运行截图已检查精灵着台、名单框右边缘与收获行；课堂、社交和社交完成弹窗沿用已通过的资产化四态验收；`tests/ranch_ui_polish_test.gd` 锁定收获和入口热区；既有牧场玩法测试继续回归 |
