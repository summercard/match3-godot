# 新手教程界面资产代入表

更新时间：2026-05-20

## 接入说明

本轮处理 `SceneTutorial` 新手引导界面。参考 `美术开发/概念图/15_新手教程_tutorial.png` 的战斗覆盖层结构：战斗背景、怪物、宝石、血条、队伍卡全部复用已有通用运行资产；教程专属部分只制作标题牌、提示面板、跳过/下一步按钮、发光框、滑动箭头、虚线路径、手势和目标卡。

本轮没有直接裁切概念图。教程专属资产以 image-2 风格重绘提取源输出，再拆分到正式目录和运行目录。

## 功能保留

| 功能 | 状态 |
|---|---|
| 五步新手引导流程 | 保留并美术化 |
| 跳过教程 | 保留，点击左下跳过完成教程 |
| 下一步/开始冒险 | 保留，最后一步完成教程并进入大厅 |
| 教程进度保存 | 保留，调用 `SaveManager.save_tutorial_progress()` |
| 设置页重置数据后重置教程 | 已完成，重置后写入 `currentStep=0/completed=false` |

## 质量约束

| 风险 | 处理方式 |
|---|---|
| UI 重叠 | 顶栏、棋盘、提示面板、按钮均使用固定 Rect 分区 |
| 图标拉伸 | 怪物、宝石、手势、捕获球统一 contain 绘制 |
| 点击区错位 | 跳过与下一步按钮点击区与视觉 Rect 同源 |
| 重复资产 | 怪物、宝石、战斗背景、捕获球均复用通用资产，不进入 tutorial 目录 |
