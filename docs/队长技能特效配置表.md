## 技能组合与播放间隔

`start` 表示相对技能开始的秒数，`duration` 是该步骤播放秒数。

| 技能配置 | 释放步骤 | 中段步骤 | 受击步骤 | 总时长 |
| --- | --- | --- | --- | --- |
| `fire`（火球术） | `fire_release_a` 0.00 / 0.50 | `fireball_sprite_b` + `fireball_trail_b` 0.20 / 1.00，15° 弧线 | `fire_impact_c` 1.20 / 0.38 | 1.58s |
| `balanced`（均衡治疗） | `heal_release_a` 0.00 / 0.34 | — | `heal_rise_c` 0.18 / 0.72，长条上升 + 颗粒 | 0.90s |
| `heal`（金色群体治疗） | `gold_heal_release_a` 0.00 / 0.40 | — | `gold_heal_all_c` 0.22 / 0.74，对方全体同时上升治疗柱 | 0.96s |
| `speed`（疾风） | `release_a` 0.00 / 0.16 | `wind_lightning_link_b` 0.10 / 1.00；固定直线 + 动态闪电曲线 | `wind_lightning_hit_c` 0.10 / 1.00；与连线同步持续 | 1.10s |
| `guard`（潮汐连锁） | `tidal_release_a` 0.00 / 0.28 | 大水球 A→B 0.12 / 0.64；小水球 B→C 0.92 / 0.42 | B 水花 0.76 / 0.30；C 水花 1.34 / 0.30 | 1.64s |
| `bulwark`（岩壁连投） | `rock_release_a` 第 0.00 / 0.30 / 0.60 秒，各 0.22s | `rock_flight_b` 第 0.08 / 0.38 / 0.68 秒，各 0.72s；随机 8°–22° 弧线与左右方向，滚动 2.6 圈 | `rock_impact_c` 第 0.80 / 1.10 / 1.40 秒，各 0.32s | 1.72s |
| `siphon` | `release_a` 0.00 / 0.20 | `link_b` 0.12 / 0.32 | `shadow_c` 0.38 / 0.30 | 0.68s |
| `chain` | `release_a` 0.00 / 0.16 | `link_b` 0.10 / 0.32 | `thunder_c` 0.34 / 0.28 | 0.62s |

例如，火球术在 `SKILL_SEQUENCES` 填写：`fire_release_a → fireball_sprite_b + fireball_trail_b → fire_impact_c`。释放特效持续 0.5 秒；火球主体与单粒子拖尾在第 0.2 秒共同挂到飞行节点，因此会与释放尾段重叠 0.3 秒，随后按 15° 上拱二次贝塞尔曲线飞行 1 秒；第 1.2 秒抵达目标，并开始受击火花。

群体治疗在受击效果块上声明 `target_scope: "all_targets"` 与 `target_group: "opponents"`。播放器只生成一次施放者释放效果，并为每个对方目标复制一条金色受击治疗效果；该技能没有飞行或连线层。

潮汐连锁使用 `source_scope: "selected_target"` 与 `target_scope: "chain_target"`：第一段把 A→B 的大水球打散，第二段将 B 自动作为新的飞行起点，把小水球弹向相邻 C；两处命中各自播放水花。

疾风是持续连线，不生成飞行物：第 0.10 秒锁定施放者 A 到目标 B 的直线，基准线保持端点不动，青白闪电折线围绕它连续变化 1 秒；目标 B 的电击受击也从同一时刻开始并持续 1 秒。

岩壁连投通过每个步骤共用 `repeat_count: 3` 与 `repeat_interval: 0.30` 展开为三次播放。三发石块保持相同的大小、时长和粒子配置；播放器在每次施放开始时，为每发生成稳定的 `arc_degrees`（8°–22°）、`arc_direction`（左右）与 `roll_direction`（翻滚方向）。下一次施放会得到新的三发排列，但同一次飞行不会逐帧跳动。

## 飞行节点规则

- `arc_degrees`：节点相对施放者—目标直线的起飞/落下角度；当前火球为 `15.0`。
- `sample_flight_motion()` 返回节点的 `position`、飞行切线 `direction` 与 `rotation`。
- `rotation` 以本地 **Y 轴朝前** 计算。后续接入箭头或火球单帧贴图时，无需另写朝向逻辑；贴图的 Y 轴会持续指向节点飞行方向。
- 火球主体和拖尾各自是飞行层效果，但读取同一飞行节点，因而严格同步抵达目标。
- `random_arc_min` / `random_arc_max`：重复投射的每发随机弧线角度范围；运行时固定为该发的 `arc_degrees`。
- `random_arc_direction`：为重复投射生成固定的左右弧线方向；未启用时仍默认向上拱起。
- `roll_turns`：飞行方块在自身局部空间内完成的翻滚圈数；`roll_direction` 由重复实例稳定生成。

## 重复投射可调项

| 字段 | 用途 | 约束 |
| --- | --- | --- |
| `repeat_count` | 同一配置步骤展开的次数 | 同一发的 release、flight、hit 必须使用相同次数 |
| `repeat_interval` | 相邻两发的起播间隔（秒） | 同一发的 release、flight、hit 必须使用相同间隔，才能保持因果对应 |
| `random_arc_min` / `random_arc_max` | 每发弧线角度的取值范围 | 仅写在需要变化的飞行步骤；应保持可读、避免遮挡角色 |
| `random_arc_direction` | 每发弧线向左或向右 | 为真时由稳定种子一次性决定，不在绘制时重抽 |
| `random_arc_seed` | 重复飞行的稳定随机种子 | 只改变本次序列的排布，不产生每帧闪烁 |
| `roll_turns` | 飞行物绕自身中心滚动的圈数 | 适用于石块等有体块方向感的飞行物 |

## 方块粒子细化参数

以下参数定义在效果块内，不写死在渲染器中；后续替换真实粒子资源时仍可复用。

| 参数 | 用途 | 火球当前值 |
| --- | --- | --- |
| `particle_count` | 单次可见方块粒子数量 | 释放 7 / 拖尾 8 / 爆炸 12 |
| `particle_spread` | 出生或扩散的随机范围（像素） | 30 / 22 / 48 |
| `particle_birth_range` | 在特效开始后随机延迟出生的归一化区间 | 拖尾与爆炸均为 0.16 |
| `particle_step` | 拖尾相邻粒子的时间间距 | 0.095 |
| `particle_seed` | 稳定随机种子；保证同一次播放不逐帧跳闪 | 11 / 23 / 37 |

拖尾粒子会在火球节点后方按随机时间与横向范围出生；爆炸火花则从随机初始半径、随机角度和不同速度向外扩散。``stable_noise()`` 保证这些随机结果在每一帧都稳定。
