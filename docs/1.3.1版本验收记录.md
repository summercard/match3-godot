## 实施结果

1. 新档的三只初始精灵改为固定、互不重复的性格；旧存档不改写。
2. 主线道具与钻石仅首通发放，重复通关及扫荡不再附带道具。
3. 信箱增加存档化的投递日程与待投递邮件；每日 1–6 个稳定批次位于 09:00–21:00，附件组合在排队时固定，到期物化幂等。
4. 队长技改为单体五点蓄能与按填满顺序释放的队列；释放只清空队首精灵。队长技满点后以后台队列播放，不截断后续 combo；敌方回合前等待队长技尾声收完。五点 UI 有逐点放大回弹，普通攻击取消角色位移。
5. 战斗准备页隐藏奖励预告，使用大厅主行动按钮并上移放大；大厅移除成就分数和测试入口路由，设置页仅保留音效/音乐，农场有收益时首次点击直接收取。
6. 选关页移除顶部多余暗色遮罩；既有触摸拖动抑制、课堂/社交互斥保持不变。

## 自动化验收

执行环境使用隔离 `MATCH3_SAVE_PATH` 与固定 `MATCH3_TEST_SEED=20260622`。

```sh
rg --files tests -g '*_test.gd' | sort
# 对每个用例执行：
godot --headless --fixed-fps 60 --path . --script res://tests/<test>.gd
```

结果：**125 / 125 通过**。其中新增/扩展覆盖：

- 固定初始性格和首次社交结果；
- 首通、重复通关与扫荡奖励；
- 信箱日程、延迟物化、红点及领取链路；
- 独立队长蓄能队列、首次有效消除和攻击无位移；
- 队长技表现缩短、移除全屏暗遮罩，且释放播放不阻塞棋盘 combo；
- 准备页、大厅、设置、选关与农场交互结构。

已额外执行：`p0_smoke_test.gd`、`tower_battle_flow_test.gd`、`runtime_screenshot_gate_test.gd`、`formal_scene_resource_test.gd`。运行时截图门禁在 headless 渲染器下完成路由/状态检查，像素捕获按测试设计跳过。
