# 2026-06-01 版本精简与接手记录

## 工程结构

- `main.gd`：应用入口、375x667 竖屏布局、场景路由。
- `src/core/`：存档、场景管理、怪物实例、成长、进化、羁绊和牧场社交。
- `src/match3/`：8x8 三消棋盘、特殊宝石、障碍、锁链和毒雾。
- `src/battle/`：伤害、技能、敌方意图、捕捉窗口、奖励和 Boss 阶段。
- `src/ui/`：运行时 UI 与逐步迁移到可编辑 `PackedScene` 的界面。
- `assets/`：运行时素材。
- `tests/`：Godot headless 回归测试。

## 本轮修复

1. 新存档首次点击开始会进入教程；已有玩家数据但没有教程字段的旧存档继续跳过教程，避免迁移后强制打断。
2. 牧场侵蚀结果默认进入保护状态，不再在领取社交结果时自动删除怪物。界面会显示风险警报，后续如开放吞噬收益，必须新增玩家主动确认流程。

## 本轮瘦身

以下内容与运行时和未来打包无关，已从工程移除：

- `美术开发/`：概念图、拆分过程、QA 截图、批处理脚本和备份。
- `assets/images/concepts/`：已完成参考职责的模块概念图。
- `tools/`：一次性素材生成脚本。
- `.dev-cycle/`：本地视觉循环状态。
- `.godot/`：本地资源导入缓存，打开编辑器时按当前资产重新生成。
- 根目录旧压缩包和临时 UID。
- 已被正式素材替代、且没有代码或场景引用的旧图片。

`docs/.gdignore` 用于阻止设计文档参与 Godot 资源扫描。设计文档保留在仓库中，旧文档继续放在 `docs/archive/`。

`tests/` 继续保留为开发期回归入口，不属于运行时业务资产。

## 自检入口

使用 Godot 4.6.x 执行：

```powershell
godot --headless --path . --script res://tests/p0_smoke_test.gd
```

完整回归时逐个执行 `tests/` 下除视觉截图辅助脚本外的测试脚本。
