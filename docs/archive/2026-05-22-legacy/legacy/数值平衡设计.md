# 数值平衡设计 — 成长曲线与兴趣曲线

> 核心原则：**专业优先于新内容**。先把数值体系设计好，再考虑加新怪物/新章节。
> 设计目标：新手3分钟内打赢第一场，10分钟内理解成长循环，30分钟内感受到"变强了"。

---

## 一、设计哲学

### 1. 心流理论（Flow Theory）
```
挑战难度
  ↑
  |          ┌────── 最优体验区（心流）
  |         /│
  |        / │
  |       /  │ ← 焦虑区（太难 → 挫败）
  |      /   │
  |     /    │
  |    /     │
  |───/──────┼──────→ 玩家能力
  |  /       │
  | /        │ ← 无聊区（太简单 → 无趣）
  |/         │
  └──────────┘
```

**目标：** 关卡难度始终略高于玩家当前能力（约 1.1-1.3x），让玩家需要思考但不会卡关。

### 2. 兴趣曲线（Interest Curve）
```
兴趣
  ↑     ●高潮        ●高潮
  |    / \          / \
  |   /   \        /   \
  |  /  ●低谷     /  ●低谷
  | /   (探索)   /   (养成)
  |/            /
  ● 开场        ● 中场转折
  └────────────────────────→ 游戏进度
  Ch1-2  Ch3  Ch4-5  Ch6  Ch7-8  Ch9  Ch10
```

- **Ch1-2（草原/烈焰）**：轻松上手，建立信心，兴趣快速上升
- **Ch3（神秘森林）**：引入新机制，略微难一点但不过分
- **Ch4-5（幽暗/雷电）**：难度稳步上升，引入进化系统
- **Ch6（冰雪）**：中场低谷——偏探索和养成，让玩家消化
- **Ch7-8（虚空/时空）**：难度跳升，新属性，中期高潮
- **Ch9（星耀）**：低谷——刷材料/养成
- **Ch10（混沌）**：终局高潮，最终BOSS

### 3. D1 留存原则
- **第1场战斗**：必须在 60 秒内结束，且玩家必须赢
- **第1次收服**：必须在第1-2关发生，收服概率 ≥80%
- **第1次进化**：在 Ch3-4 解锁，让玩家感受到成长

## 二、核心公式

### 2.1 属性成长公式

```
怪物属性 = baseStat × growthMultiplier(level)

growthMultiplier(level) = 1 + (level - 1) × growthRate

growthRate 按稀有度：
- ★1 (普通敌人): 0.08/级
- ★2 (常见):     0.10/级
- ★3 (稀有):     0.12/级
- ★4 (史诗):     0.14/级
- ★5 (传说):     0.16/级
```

**设计意图：** 稀有度高的怪物不仅基础强，成长率也高，后期差距越拉越大。

### 2.2 伤害公式

```
最终伤害 = ATK × skillMultiplier × comboBonus × elementBonus × (1 - DEF_reduction) × randomVariance

其中：
- skillMultiplier = gemCount / 3（最低1.0，保底伤害）
- comboBonus = 1 + (cascade - 1) × 0.30（每次连锁 +30%）
- elementBonus = 1.5（克制）/ 0.75（被克）/ 1.0（普通）
- DEF_reduction = targetDEF / (targetDEF + 100)（上限50%）
- randomVariance = 0.9 ~ 1.1（±10%浮动）

敌方伤害：
- baseMultiplier = 0.6 ~ 0.9（比玩家弱，防止秒杀）
- DEF_reduction = targetDEF / (targetDEF + 80)
```

### 2.3 收服公式

```
收服概率 = baseCaptureRate × (1 - currentHP/maxHP) × levelBonus

baseCaptureRate：
- ★1 敌人: 0.60
- ★2 怪物: 0.40
- ★3 稀有: 0.25
- ★4 史诗: 0.15
- ★5 传说: 0.08

levelBonus = 1 + (playerLevel - enemyLevel) × 0.05（等级差加成，上限1.5x）
```

## 三、新手体验（Ch1-Ch2）数值目标

### 3.1 第一关：stage_1_1 新手训练

**玩家（Level 5 默认队伍）：**

| 怪物 | HP | ATK | DEF | 属性 |
|------|-----|-----|-----|------|
| 小火龙 | 180×1.4=252 | 45×1.4=63 | 30×1.4=42 | fire |
| 水龟仔 | 200×1.4=280 | 35×1.4=49 | 40×1.4=56 | water |
| 草苗儿 | 170×1.4=238 | 38×1.4=53 | 35×1.4=49 | grass |

**敌人（Level 1，2只弱怪）：**

| 怪物 | HP | ATK | DEF | 属性 |
|------|-----|-----|-----|------|
| 野火虫 | 40×1.0=40 | 10×1.0=10 | 5×1.0=5 | fire |
| 水泡泡 | 35×1.0=35 | 8×1.0=8 | 8×1.0=8 | water |

**伤害模拟：**
- 玩家一次3消：63 × 1.0 × 1.0 × (1 - 5/105) = 60 → 两回合击杀野火虫
- 敌人一次攻击：10 × 0.75 × (1 - 42/122) = 5 → 每回合总受伤约10
- 预计通关：3-4回合，玩家剩余 HP ≥90%
- **结论：碾压局，建立信心 ✅**

### 3.2 第二章Boss关：花叶兽

**敌人（Level 5 Boss）：**

| 怪物 | HP | ATK | DEF |
|------|-----|-----|-----|
| 花叶兽 | 350×1.4=490 | 45×1.4=63 | 35×1.4=49 |

**目标：** 8-12回合内击杀，玩家剩余 HP ≥40%
- 玩家平均每回合伤害：~120（3个怪物各一次3消 + 属性克制）
- Boss每回合对玩家伤害：63 × 0.75 × 2（打两个目标）× (1 - 42/122) ≈ 54
- 10回合内玩家总受伤：540，三人总 HP 770 → 剩余约 30-50%
- **结论：有压力但能赢，感受到挑战 ✅**

## 八、玩法丰富度路线图（2026-05-14 评估）

### 核心问题

**每一关体验完全一样**：一样的空棋盘、一样的5种宝石、一样的操作方式。从 Ch1 到 Ch11 没有任何新机制引入。

### 渐进式引入计划（循序渐进，每个阶段只加1-2个机制）

#### 阶段 A：消除深度（最先做，改动小体验大）

| ID | 机制 | 说明 | 引入章节 | 状态 |
|----|------|------|---------|------|
| A1 | 4连强化宝石 | 4连消产生发光宝石，引爆时十字范围伤害 | Ch2 | ✅ |
| A2 | 5连彩虹宝石 | 5连消产生彩虹宝石，全屏消除同色 | Ch3 | ☐ |
| A3 | L/T形消除 | 非线性匹配产生炸弹宝石 | Ch5 | ☐ |

#### 阶段 B：棋盘变化（让每关感觉不同）

| ID | 机制 | 说明 | 引入章节 | 状态 |
|----|------|------|---------|------|
| B1 | 障碍物格子 | 石块/冰块占据格子，需相邻消除打破 | Ch2 | ✅ |
| B2 | 锁定宝石 | 宝石被锁不能移动，需消除同色解锁 | Ch4 | ✅ |
| B3 | 毒雾格子 | 一定回合后扩散，碰到扣HP | Ch6 | ☐ |

**B2 锁定宝石详细设计（v1.0 — 2026-05-15）**
- **核心机制**：锁定宝石不可移动/交换，但可参与3连消除
- **解锁方式**：消除与锁定宝石同色的相邻宝石（上下左右），每消除1个相邻同色 → lockHP-1
- **锁链HP**：普通关 HP=1（一次解锁），Boss关 HP=2（需两次）
- **重力交互**：锁定宝石不参与重力下落（固定位置），解锁后正常参与
- **视觉标识**：锁链⛓️边框环绕宝石，HP≥2时中心显示🔒
- **解锁动画**：碎裂扩散 + "🔓解锁!" 浮动文字
- **引入关卡**：Ch4 幽暗森林（stage_4_2起），循序渐进
  - stage_4_2: 2个锁定(HP=1)
  - stage_4_3: 3个锁定(HP=1)
  - stage_4_4: 4个锁定(HP=1)
  - stage_4_5 Boss: 6个锁定(HP=2)
- **策略深度**：玩家需要考虑"在哪里消除"而非只追求"消得多"

#### 阶段 C：战斗策略（让队伍搭配有意义）

| ID | 机制 | 说明 | 引入章节 | 状态 |
|----|------|------|---------|------|
| C1 | 敌人特殊行为 | Boss蓄力/护盾/回血，不只随机攻击 | Ch2 Boss | ☐ |
| C2 | 队长技能 | 队长提供被动加成（如火属性伤害+30%） | Ch4 | ☐ |
| C3 | 属性协同 | 同属性队伍额外加成 | Ch5 | ☐ |
| C4 | 状态效果 | 消除特定组合附加中毒/灼烧/眩晕 | Ch7 | ☐ |

#### 阶段 D：关卡差异化

| ID | 机制 | 说明 | 引入章节 | 状态 |
|----|------|------|---------|------|
| D1 | 精英关卡 | 1个强力怪+特殊棋盘布局 | Ch2 | ✅ |
| D2 | 宝箱关卡 | 限时消除获取奖励，无战斗 | Ch3 | ☐ |
| D3 | 限时挑战 | 限制回合数的特殊关卡 | Ch4 | ☐ |

### 评判标准

每个新机制引入前必须回答：
1. **玩家能理解吗？** 不需要文字说明就能发现
2. **有即时正反馈吗？** 触发时有明显视觉/数值反馈
3. **增加深度还是增加复杂度？** 深度=更多策略选择，复杂度=更多要记的规则
4. **循序渐进了吗？** 前面的机制玩家熟练后才引入下一个

### 执行顺序

```
A1（4连强化）✅ → A2（5连彩虹）→ B1（障碍物）→ C1（敌人AI）→ D1（精英关）
```

**A1 是第一步**：改动只涉及 board.js + sceneBattle.js，不需要新数据结构，玩家立刻感受到"消4个比消3个厉害"。

### eliteMultiplier 公式
```
最终HP = baseHP × eliteMultiplier
最终ATK = baseATK × eliteMultiplier
```

## 九、C2 队长技能设计

### 设计目标
让队伍编成有策略意义，不是简单堆战力。谁当队长产生实际差异。

### 机制概述
- **队长位置**：队伍第1个槽位（index 0）自动成为队长
- **解锁条件**：★3（稀有）及以上的怪物才拥有队长技能
- **触发方式**：被动技能，战斗全程自动生效

### 技能类型

| 类型 | 名称示例 | 效果 | 分配策略 |
|------|----------|------|----------|
| **属性攻击加成** | 烈焰之心 | 同属性宝石伤害+30% | 按怪物主属性分配 |
| **全队防御加成** | 钢铁意志 | 全队受到伤害-15% | 高防/坦克型怪物 |
| **全队HP加成** | 生命之泉 | 全队HP+20% | 高HP/Boss怪物 |
| **初始Combo** | 先手必胜 | 战斗开始自带1层combo | 高速型怪物 |

### 数值设计
- ATK_BOOST: 对应属性宝石伤害 × 1.3（30%加成）
- DEF_BOOST: 受伤 × 0.85（15%减免）
- HP_BOOST: 全队HP × 1.2（20%加成）
- COMBO_START: 初始 combo = 1

### 分配规则
- ★3 怪物：大多数为同属性ATK_BOOST，高速型为COMBO_START，高防型为DEF_BOOST
- ★4 怪物：延续进化前技能或升级为DEF_BOOST/HP_BOOST
- ★5 Boss：拥有独特强力技能（ATK_BOOST对应属性 或 HP_BOOST）
- ★1-2 怪物：无队长技能 → 鼓励收服稀有怪物

### 引入时机
- 新手三件套(★2)没有队长技能
- Ch3-4 开始出现★3怪物，玩家自然接触到队长技能
- 队伍编成页面队长槽位显示👑标记和技能描述
