# MATCH3 UI 美术制作与验收标准

## 目的

本标准用于 `match3-godot` 的 UI 美术制作、资产提取、界面拼装和最终验收。所有由概念图驱动的新界面，都必须按此流程执行。

## 制作工具标准

- 概念图资产提取必须先使用 `image-2`。
- 概念图只能作为参考或输入源，不能直接裁切后作为正式资产。
- `image-2` 输出后，必须再进行透明通道、裁边、尺寸、命名和 Godot 导入验收。
- 正式界面以 `tscn` 为准，运行时必须通过 `PACKED_SCENE_MAP` 进入同一个场景。
- 最终验收以 Godot 运行截图为准，不以编辑器静态画面为准。

## 可以做

- 使用 `image-2` 从概念图中提取干净 UI 元素。
- 使用 `image-2` 重绘被角色、文字、背景遮挡的 UI 元素。
- 复用已确认的新资产，例如大厅货币栏、农场底部导航、背包卡片、商店按钮和图鉴图标。
- 对 `image-2` 输出做 alpha 清理、裁边、缩放和格式规范化。
- 新建正式资产目录，例如 `assets/images/<page>_new/`。
- 为按钮、切页、领取、选中态和跳转加入反馈动画。
- 建立或更新正式 `tscn`，并接入 `main.gd` 的 `PACKED_SCENE_MAP`。

## 不可以做

- 不可以直接把概念图裁切后放进正式界面。
- 不可以让正式场景引用 `assets/MATCH3美术资产/...` 原始目录。
- 不可以使用旧 UI 资产冒充新资产。
- 不可以把带背景、角色遮挡、文字遮挡、压缩噪点的概念图碎片当正式资产。
- 不可以出现棋盘格、绿边、白边、灰边、脏透明或半透明误抠。
- 不可以因为按钮是绿色或高光是浅色，就把主体误抠成透明。
- 不可以只改脚本绘制、不接 `tscn`。
- 不可以只看编辑器，不跑运行截图。
- 不可以遗漏按钮反馈动画。

## 资产制作标准

1. 先根据概念图拆解需要的 UI 元素。
2. 能复用已有新资产时优先复用。
3. 不能复用的元素，用 `image-2` 提取或重绘。
4. 输出 PNG 后检查 alpha 通道。
5. 清理边缘脏色，但保留高光、描边和阴影。
6. 裁掉多余透明画布，不能直接使用超大原图。
7. 按功能命名，例如 `ui_achievement_card.png`、`icon_nav_home.png`、`bg_team_hall.png`。
8. 放入正式目录，例如 `assets/images/achievement_new/`。
9. 导入 Godot 后在运行截图中检查缩放、清晰度和边缘。

## 界面拼装标准

- 顶部货币栏、底部导航等共享组件应复用同一套已确认资产。
- 当前页面必须有明确选中态。
- 背景、主面板、标题、按钮、卡片和列表的比例要对齐概念图。
- 文案不能乱码、压边、重叠或被图标遮挡。
- 图标不能过大、过小、发虚或有脏边。
- 所有可点击控件必须有反馈动画。
- 跳转按钮应保留短反馈时间后再切场景。

## 交互反馈标准

按钮至少应有以下一种或多种反馈：

- 按下缩小。
- 松手回弹。
- 发光或描边。
- 放射线或闪光。
- 选中态底板。
- 领取成功、切页、切换分类等状态变化。

重要按钮建议使用缩放、回弹和闪光组合，并在跳转前保留约 `0.10-0.20s` 的反馈时间。

## 验收流程

1. 检查概念图与新资产来源。
2. 确认概念图元素已通过 `image-2` 提取或重绘。
3. 检查正式资产目录和命名。
4. 检查 `tscn` 是否为正式入口。
5. 检查 `main.gd` 的 `PACKED_SCENE_MAP` 是否接入。
6. 扫描旧资产和原始概念图引用。
7. 跑 Godot 烟测。
8. 生成运行截图。
9. 肉眼验收截图。
10. 修复错位、脏边、乱码、老资产、无反馈等问题后再次截图。

## 推荐命令

Godot 烟测：

```powershell
& 'I:\Godot_v4.6.3-stable_win64.exe\Godot_v4.6.3-stable_win64_console.exe' --headless --path . -s res://tests/p0_smoke_test.gd
```

运行截图：

```powershell
& 'I:\Godot_v4.6.3-stable_win64.exe\Godot_v4.6.3-stable_win64_console.exe' --path . --resolution 375x667 -s res://tests/capture_runtime_scene.gd -- --scene-name=<scene> --settle-frames=45 --output=res://.godot/<scene>_check.png
```

旧资产/原始资产扫描：

```powershell
rg -n "assets/MATCH3美术资产|assets/images/(achievement|team/ui|shop/ui|inventory/)|assets/images/main/icon_" src/ui -S
```

## 验收结论标准

只有同时满足以下条件，才算完成：

- 正式界面走 `tscn`。
- 运行截图正确。
- 没有旧资产或原始概念图引用。
- `image-2` 产出的正式资产通过 alpha 和边缘检查。
- UI 布局和概念图风格一致。
- 文字正常。
- 按钮反馈完整。
- Godot 烟测通过。
