## 里程碑

### M1 核心可玩（P0）

> 游戏能从启动到战斗结算跑完一整局。

- [ ] 启动场景正常显示图片和按钮
- [ ] start → main 场景切换正常
- [ ] main → stage_select → battle_prepare → battle 场景链路畅通
- [ ] 三消棋盘可交互（鼠标拖拽交换 + 消除 + 连锁）
- [ ] 战斗流程完整（我方消除攻击 → 敌方回合 → 胜负判定）
- [ ] result 结算页显示战斗结果
- [ ] 存档保存/加载正常

**验收标准：** 打开游戏 → 点开始 → 选关 → 进战斗 → 打完一局 → 回主菜单，全程无崩溃。
