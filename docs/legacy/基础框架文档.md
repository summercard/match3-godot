## 架构设计

### 核心设计理念
1. **纯代码 UI**：所有场景 extends Control，在 `_ready()` 中动态创建节点，不依赖 .tscn
2. **Autoload 单例**：SceneManager / GameManager / SaveManager 全局可用
3. **信号驱动**：Godot 内置 signal 替代 EventBus，解耦模块间通信
4. **数据驱动**：怪物、关卡等数据内嵌在 `_db.gd` 文件中，逻辑与数据分离
5. **模块拆分**：战斗系统拆分为 5 个子模块，职责单一

### 游戏启动流程
```
main.tscn 加载
  → main.gd._ready()
    → SceneManager.switch_scene("start")
      → scene_start.gd._ready()
        → _create_ui()   # 动态创建所有 UI 节点
        → _init_data()   # 初始化数据
```

### 场景切换机制
```gdscript
# SceneManager (Autoload)
func switch_scene(scene_name: String) -> void:
    # 1. 移除当前场景
    # 2. 根据名称创建新场景实例
    # 3. 添加到场景树
    # 4. 新场景 _ready() 自动执行
```

### 信号系统
```gdscript
# 替代微信版 EventBus 的全局信号
signal gem_matched(element: String, count: int)     # 宝石消除
signal damage_dealt(target, amount: int)             # 造成伤害
signal turn_ended()                                  # 回合结束
signal scene_changed(scene_name: String)             # 场景切换
signal capture_attempt(monster_id: String)           # 尝试捕获
signal capture_success(monster_id: String)           # 捕获成功
signal player_data_changed()                         # 玩家数据变化
```

### 三消核心算法
```
1. 用户拖拽交换两个相邻宝石
2. 检查是否有3连以上匹配
   - 无匹配 → 交换回来（带动画）
   - 有匹配 → 进入消除流程
3. 消除匹配的宝石（带动画）
4. 触发战斗伤害（根据消除的属性）
5. 重力下落填充空位（带动画）
6. 检查新的匹配（连锁反应）
7. 重复3-6直到无新匹配
8. 敌方行动
9. 回合结束
```

## 与微信版的关键差异

| 方面 | 微信版 (Canvas/JS) | Godot 版 (GDScript) |
|------|-------------------|---------------------|
| 渲染 | Canvas 2D 手动绘制 | Godot Control 节点树 |
| 输入 | wx.onTouchStart/Move/End | Godot Input + gui_input 信号 |
| 事件 | EventBus 自定义 | Godot 内置 signal |
| 场景 | scene.js 手动管理 | SceneManager Autoload |
| 动画 | requestAnimationFrame + 手动插值 | Godot Tween + AnimationPlayer |
| 存储 | wx.setStorageSync | JSON 文件读写 (user://) |
| 资源 | 手动 Image 加载 | preload / load (res://) |
| 布局 | Canvas 坐标计算 | Control 锚点 + 容器 |
| 字体 | ctx.font | Label + Theme 覆盖 |

## 纯代码 UI 规范

### 场景模板
```gdscript
extends Control
class_name SceneXxx

func _ready() -> void:
    name = "SceneXxx"
    set_anchors_preset(Control.PRESET_FULL_RECT)
    _create_ui()
    _init_data()

func _create_ui() -> void:
    # 所有 UI 元素在这里动态创建
    pass

func _init_data() -> void:
    # 加载数据、绑定信号
    pass

func _go_to_scene(scene_name: String) -> void:
    SceneManager.switch_scene(scene_name)
```

### 编码规范
- 节点变量：`var` 声明（不用 @onready），在 `_create_ui()` 中赋值
- 位置/大小：`Vector2` / `Rect2`
- 锚点：`set_anchors_preset()`
- 按钮事件：`button.pressed.connect(callback)`
- 颜色：`Color(#hex)` 或 `Color.from_string()`
- 字体大小：`add_theme_font_size_override()`
- 图片加载：`Texture2D` + `preload("res://path")`

## 性能考量

- **纯代码 UI**：每次场景切换重新创建节点，注意释放旧节点（`queue_free()`）
- **图片资源**：使用 preload 预加载，避免运行时 IO
- **三消棋盘**：8×8 = 64 个宝石节点，需要对象池复用
- **动画**：使用 Godot Tween，避免手动 `_process` 插值
