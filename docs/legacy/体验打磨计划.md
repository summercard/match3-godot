## 设计规范（Godot GDScript）

### 色调系统（theme.gd）
```gdscript
const PRIMARY := Color("#2979ff")
const PRIMARY_DARK := Color("#1565c0")
const BG_DARK := Color("#0a0a1a")
const BG_CARD := Color("#16213e")
const TEXT_PRIMARY := Color("#ffffff")
const FIRE := Color("#ff6b35")
const WATER := Color("#4fc3f7")
const GRASS := Color("#66bb6a")
const THUNDER := Color("#ffd54f")
const LIGHT := Color("#e0e0e0")
const SUCCESS := Color("#4caf50")
const DANGER := Color("#f44336")
const GOLD := Color("#ffd700")
```

### 字体规范
```
标题：22px bold 白色
副标题：16px bold 白色
正文：14px normal #cccccc
辅助：12px normal #888888
数值：16-18px bold（状态色）
```

### 按钮规范
```gdscript
# primary: 蓝底白字圆角
# secondary: 深灰底白字
# danger: 红底白字
# gold: 金底白字
# 按下: scale 0.95 + 颜色变暗
```

### 动画规范（Godot Tween）
```
淡入: modulate.a 0→1, 300ms, ease_out
滑入: position.x + offset + modulate.a, 200ms
按钮按下: scale 0.95, 100ms
弹出: scale 0→1.1→1, 300ms, ease_out
飘字: position.y -30px + modulate.a 1→0, 800ms
震动: position.x ±3px 循环, 200ms
```
