# 设计文档索引

## 版本规则

- 当前设计文档使用 `v主版本.次版本.修订版本`。
- 主版本：核心产品方向、玩法契约或商业化结构发生重定义。
- 次版本：新增或重构一个重要系统、章节设计框架或数值框架。
- 修订版本：措辞、表格、开发顺序、局部规则和校准记录更新。
- 文档头部版本号是该文档自己的版本；本索引负责汇总当前设计源版本。
