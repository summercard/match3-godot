# 战斗体感优化：粒子飞行可观测 + 颗粒放大（2026-11-10）

## 背景
主人实测：攻击粒子飞行太快，肉眼看不到过程；颗粒偏小，整体打击体感不足。

## 现状（main 4a6cac0，src/ui/components/element_flight_effect.gd CONFIG）
- 施法 0.18s / 飞行 0.24s / 命中 0.25s（三段合计 0.42s）
- 粒子边长 6–10px，速度 86–138，寿命 0.22s
- 弹体半径 7、光晕 15、白闪 24、命中环 10→46、环宽 3、拖尾 14 段
- 单次命中粒子 2/4/6（轻量/均衡/华丽）

## 改动目标（数值即验收口径）
1. 飞行可观测：flight_duration 0.24 → 0.60；cast 0.18 → 0.22；hit 0.25 → 0.30；total 随之 0.92。飞行段前 30% 加速、后 30% 减速，中段匀速，全程可见弹体与拖尾。
2. 颗粒加大：particle_size 6–10 → 10–16（方形像素块口径不变）；particle_speed 86–138 → 160–240；particle_life 0.22 → 0.32。
3. 命中更重：orb 7 → 11、glow 15 → 24、flash 24 → 36；命中环 10→46 改为 16→72，环宽 3 → 4；拖尾上限 14 → 22。
4. 数量：tier_particles 2/4/6 → 4/8/12；tier_budgets.particles 4/8/12 → 8/16/24；projectile_floor 不变（每格都要飞）。
5. 打击停顿：命中瞬间表现计时冻结 0.06s（只冻结特效计时，不改战斗状态/伤害/随机数），震屏幅度 +50%。

## 硬约束
- 不改伤害公式、棋盘、随机数、战斗时序；不插 await。
- 画质三档都要有对应值，轻量档不得超预算。
- 修改落在 **jiexika 分支**，不新开分支、不建 PR。
