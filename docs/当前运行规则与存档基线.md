## 1. 新档与“初始化游戏”

设置页的“初始化游戏”调用 `SaveManager.reset_to_initial_state()`，会直接保存一份确定的新档，而不是只清空当前画面。

| 项目 | 初始化结果 |
|---|---|
| 玩家 | Lv.1、经验 0、金币 0、钻石 0、体力 5 / 5；主线定位到第 1 章第 1 关 |
| 精灵与队伍 | 仅保留三只初始精灵，均为初始等级 6、固定且互不重复的性格；三只自动编入队伍 |
| 精灵图鉴 | 仅解锁这三种已拥有精灵；未拥有精灵保持锁定。图鉴的解锁依据是已拥有的物种，而非展示列表或调试数据 |
| 物品与进度 | 背包、关卡星级、成就、签到、奖励统计、教程、共鸣塔、远行信箱与牧场社交进度重置 |
| 牧场 | 3 个空闲栏位，无专注培养和社交场所记录 |
| 设置 | 音效、音乐开启；旧档兼容字段仍保留其默认值。设置 UI 只展示音效、音乐；自动捕捉关闭，捕捉/战斗道具均不装备 |

初始化会覆盖当前本机存档，测试或演示前应先确认不需要保留该档。

## 2. 等级、关卡与功能解锁

玩家经验来自主线结算和已三星关卡的扫荡；两条路径都在同一存档事务中增加玩家经验。当前等级为 `L` 时，升至 `L+1` 所需经验为：

```text
80 + 10 × L + max(0, L - 30)²
```

因此 30 级前是线性成长，31 级起加入二次项。以当前关卡奖励、只计算主线首次通关且均三星、无日常或扫荡额外经验的参考路径，玩家约在**第 3 章第 11 关后达到 Lv.25**；实际会随扫荡、奖励和版本数值调整而提前或延后。

| 功能 | 解锁条件 | 未满足时 |
|---|---:|---|
| 精灵课堂 | 玩家 Lv.1 | 新档即开放 |
| 精灵农场 | 玩家 Lv.10 | 显示等级条件，不进入牧场功能页 |
| 社交广场 | 玩家 Lv.25 | 显示等级条件，不进入社交页 |
| 共鸣塔 | `stage_1_8` 通关 | 大厅入口显示主线条件 |
| 远行信箱 | 无等级/关卡门槛 | 大厅可直接进入 |

等级门槛统一由 `FeatureUnlockRules` 判定；不要在各个 UI 单独复制常量。

## 3. 图鉴与远行信箱的收藏星星

- 图鉴条目只在玩家首次拥有对应物种时解锁；出售最后一只同物种不会重新锁定已解锁图鉴。
- 远行信箱的“图鉴星星总量”初始为三颗，对应三种初始精灵。
- 通过捕捉、奖励或其他正常入库路径**首次获得一种新精灵**时，自动增加一颗星星。
- 重复获得同物种、出售后再次获得、送出祝福、收到回信、阅读邮件和领取附件都不会增加星星。
- 已计星的物种 ID 会随存档保存，使星星发放可重试且不重复。

远行信箱每天最多送出 3 次祝福；收件箱最多保留 30 封邮件。塔阶段奖励和祝福附件均通过带收据的领取事务发放，重复点击或恢复存档不会重复给奖励。

祝福不会立即进入收件箱：每天以稳定伪随机方式生成 1–6 个、位于 09:00–21:00 的投递批次。送出后写入 `pending_blessings`，到期时由统一读取入口幂等物化到 `inbox`；已排队的正文、附件与投递时间不会因重开游戏重掷。大厅一次只播放一个未展示的抵达表现。

## 4. 1.2 共鸣塔与信箱的持久化边界

- 共鸣塔独立保存赛季、当前层/波次、安全点、队伍/棋盘快照、塔内增益、最高层、最高单回合伤害和已领取阶段奖励；不写入主线星级或主线扫荡进度。
- 每一波会保存可恢复状态；Boss 后更新安全点。失败回退安全点，但已领取的阶段奖励不回滚。
- 塔奖励仅以邮件附件进入远行信箱，领取后才进入玩家背包/货币；发送祝福和陌生来信与塔奖励使用同一邮件领取保护。
- 旧存档加载时会补齐新增的塔和信箱数据段，保留已有玩家、队伍、背包、关卡和牧场数据。

## 5. 1.3.1 主线奖励、队长技与界面口径

- 主线的钻石和 `guaranteedItems` 只在首通结算；重复胜利只给金币、玩家经验和共享精灵经验。扫荡始终只给 80% 金币/经验。
- 每名存活且拥有队长技的精灵独立积累 5 点蓄能。达到满点即按填满顺序进入队列；一次释放只清空该精灵，死亡或无效队首会安全跳过。
- 每次有效消除段都会立即产生伤害、命中与蓄能事件，并携带 `cascade_index`；满点队长技会进入后台播放队列，不阻塞后续棋盘 combo，敌方回合前再等待队长技尾声收完。
- 战斗准备页不预告结算奖励，主按钮使用大厅主行动资源；大厅不显示成就分数或测试工具入口，信箱位于左上状态区附近。
- 设置页只保留音效、音乐。农场槽位有可收经验时，第一次点击直接收取；无收益时才选中槽位。
