# 队长技能特效分层与资产表

代码总表：[`src/data/leader_skill_visual_db.gd`](../src/data/leader_skill_visual_db.gd)。该表把技能的视觉表现拆为可组合层，运行时由技能效果判定目标并绑定到对应节点中心。当前原型阶段已停用这些 PNG 的绘制，改用方形色块；新的组合与时序见《队长技能特效配置表》。

| 层 | 绑定节点 | 现有渲染 | 资产角色 |
| --- | --- | --- | --- |
| 自身释放（`release`） | 施放者角色中心 | `crest` | 各色调 512px 主特效贴图；火焰为火元素粒子 |
| 飞行（`flight`） | 施放者中心 → 目标中心 | `fire_beam` | `leader_fx_element_fire.png` |
| 连线（`link`） | 施放者中心 → 目标中心 | `beam`、雷电折线、元素拖尾 | 对应元素的 256px 粒子 |
| 受击（`hit`） | 被影响角色中心 | `impact`、`mark`、`ally_burst` | 色调主贴图与元素粒子 |

## 绑定规则

1. 先由技能逻辑确定施放者和受影响目标；角色型技能使用角色中心，棋盘操作使用棋盘单元或棋盘中心。
2. `release` 永远绑定施放者；`hit` 永远绑定被影响目标；`flight` 与 `link` 同时记录两端节点。
3. 治疗、护盾等不需要跨角色移动的技能只组合 `release + hit`。伤害与控制类技能根据色调组合 `release + flight/link + hit`。
4. 新增资产或技能时，先补代码层表与本表，再接入渲染；不得在技能分支中直接写死坐标。
