# 技能类型管理表

本项目的技能类型以 [`src/data/skill_type_table.gd`](../src/data/skill_type_table.gd) 为唯一代码表。单个精灵的数值、技能组合与说明仍放在 `monster_db.gd`、`leader_skill_db.gd`；执行逻辑分别由 `active_skill_executor.gd` 与 `leader_skill_executor.gd` 承担。

## 主动技能

| 类型 ID | 目标 | 核心参数 | 执行器 |
| --- | --- | --- | --- |
| `damage` | 最弱敌人 | `multiplier` | `_apply_damage` |
| `heal` | 最低生命队友 | `ratio`, `min` | `_apply_heal` |
| `guard` | 最低生命队友/刚治疗目标 | `reduction`, `turns` | `_apply_guard` |
| `weaken` | 最弱敌人 | `reduction`, `turns` | `_apply_weaken` |

## 队长技能

队长技的被动类型包括：`atk_boost`、`def_boost`、`hp_boost`、`combo_start`。

爆发效果按功能分为：

| 分类 | 类型 ID |
| --- | --- |
| 伤害 | `damage`, `random_multi_hit`, `damage_per_living_element_unit`, `clear_random_element_gems_damage_all`, `clear_element_gems_damage_highest_hp` |
| 治疗与防护 | `heal`, `heal_over_time`, `heal_by_gem_count`, `lifesteal`, `guard`, `team_shield`, `reflect_damage`, `self_damage_reduction` |
| 状态与属性 | `status`, `weaken`, `enemy_damage_vulnerability`, `confuse_enemy_attack`, `randomize_enemy_element`, `self_atk_boost`, `grant_ally_charge` |
| 棋盘操作 | `convert_gems`, `convert_element_gems_by_ratio`, `convert_adjacent_gems_from_random_source`, `shuffle_board`, `remove_random_element_gems` |

新增类型时：先在类型表登记名称、目标、参数与执行器；再在对应执行器实现该方法；最后才把该 `kind` 写入具体技能配置，并补充测试。
