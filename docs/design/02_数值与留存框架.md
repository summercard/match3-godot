## 1. 数值目标

数值服务于三个结果：

1. 玩家愿意继续打下一关
2. 玩家愿意养不同怪物并尝试不同队伍
3. 玩家失败后知道要换策略、换构筑或补成长，而不是只感到被墙挡住

## 2. 体验时间表

| 时间 | 玩家应获得的体验 |
|---|---|
| 1 分钟 | 第一战胜利，理解三消驱动怪物行动 |
| 5 分钟 | 首次捕捉成功，知道怪物能带回队伍 |
| 10 分钟 | 首次技能职责差异，出现一个队伍选择 |
| 30 分钟 | 打过第一个有破招点的 Boss，形成初步构筑偏好 |
| 1 天 | 有一只想继续培养的怪物，有一个想补齐的怪物生态 |
| 1 周 | 能回看自己的队伍演化，而不是只看到等级变高 |

## 3. 战斗节奏包线

先用目标包线校准数值，再做章节铺量。

| 内容 | 目标回合 | 目标失败率 | 设计说明 |
|---|---:|---:|---|
| Ch1 普通关 | 2-4 | 极低 | 建立爽感 |
| Ch1 Boss | 6-8 | 低 | 教会破招 |
| 中期普通关 | 4-7 | 低到中 | 强调棋盘与队伍选择 |
| 精英关 | 6-9 | 中 | 奖励准备和机制理解 |
| 中后期 Boss | 8-12 | 中 | 允许一次失误，不允许无脑磨 |

失败率需要结合玩家分层看：

- 首次游玩
- 推荐等级
- 低一档成长
- 高一档成长
- 正确构筑
- 泛用构筑

## 4. 战斗数值结构

## 4.1 伤害预算

一场战斗的表现力应来自多层贡献，而不是单一攻击力：

| 来源 | 目标职责 |
|---|---|
| 基础 3 消 | 保底推进 |
| 优质消除与连锁 | 明显提速 |
| 技能释放 | 创造窗口或处理机制 |
| 构筑克制 | 提供稳定优势 |
| 成长数值 | 允许卡关后补强 |

经验规则：

- 普通敌人不能要求玩家每回合都打出高连锁才可推进。
- Boss 不能允许纯基础 3 消无判断磨过全部机制。
- 技能强度要同时看伤害、控场、塑盘和捕捉收益，不能只看倍率。

## 4.2 垂直与横向成长比例

前期允许等级带来明显安全感；中后期把胜率提升更多交给构筑和机制理解。

建议目标：

| 阶段 | 垂直成长主导 | 构筑与操作主导 |
|---|---:|---:|
| 前 30 分钟 | 60% | 40% |
| 中期 | 45% | 55% |
| 长线 | 35% | 65% |

这不是伤害公式硬拆分，而是关卡调参时的设计约束。

## 4.3 稀有度原则

稀有怪可以更强，但低稀有怪不能只做过渡垃圾。

稀有度主要提供：

- 更高成长上限
- 更复杂或更通用的技能
- 更好的羁绊分支

低稀有怪保留价值的方式：

- 费用低
- 技能专精明确
- 捕捉培养快
- 对特定章节机制有好解

## 5. 经济与成长循环

## 5.1 资源层级

| 资源 | 职责 | 主要获得 | 主要消耗 |
|---|---|---|---|
| 金币 | 日常通用资源 | 关卡、扫荡、签到 | 道具、基础培养 |
| 玩家经验 | 解锁节奏 | 关卡 | 账号进度 |
| 怪物经验 | 队伍成长 | 出战、牧场、道具 | 等级 |
| 进化材料 | 阶段爆点 | 章节节点、目标奖励 | 进化 |
| 捕捉道具 | 降低风险 | 掉落、商店、任务 | 捕捉 |
| 章节生态奖励 | 收藏与构筑 | 首通、图鉴、小目标 | 特定培养 |

## 5.2 经济约束

- 首通奖励解决“尝新”的动力。
- 扫荡奖励解决“已掌握内容”的材料回收。
- 日常奖励给稳定推进，不给大量越级碾压。
- 商店售卖短期补给和选择权，不让核心构筑只靠买。

## 5.3 成长节奏

第一版目标：

- 初始队伍在 Ch1 内至少出现 1 次明显升级反馈。
- 第一次进化准备在玩家形成队伍偏好后出现，不早到变成教程弹窗，也不晚到失去期待。
- 新怪物加入后要能较快进入可试用状态，避免收藏物永远追不上主队。

建议提供追赶机制：

- 新捕捉怪物按章节获得基础等级底线
- 牧场支持定向补经验
- 低等级怪出战获得追赶加成

## 5.4 怪物成长追赶第一版

追赶机制的目标不是让所有怪物等级一致，而是让新捕捉怪物能较快进入“可以试用”的区间。

第一版采用低风险口径：

| 规则 | 口径 |
|---|---|
| 参考等级 | 当前队伍最高等级 |
| 触发条件 | 出战怪物低于参考等级 2 级或以上 |
| 追赶倍率 | `1 + (等级差 - 1) * 0.25`，最高 2.0 倍 |
| 经验来源 | 只影响战斗结算发给存活出战怪物的怪物经验 |
| UI 反馈 | 队伍界面显示“追赶 x倍率”，结算页显示实际获得经验 |

暂不把追赶加到扫荡和未出战怪物上，避免玩家只靠后台收益绕过构筑尝试。

## 5.5 牧场专注培养第一版

牧场专注培养将追赶机制扩展到一个可控的局外选择，但只对玩家主动指定的牧场怪物生效。

| 规则 | 口径 |
|---|---|
| 基础收益 | 每 5 分钟 `5 + 怪物等级` 经验 |
| 专注对象 | 牧场里当前选中的一只怪物 |
| 专注追赶 | 专注对象低于队伍最高等级 2 级或以上时，沿用 5.4 的追赶倍率，最高 2.0 倍 |
| 陪伴收益 | 牧场每多 1 个同伴，经验倍率 +15%，最高 +45% |
| 非专注怪物 | 只吃陪伴收益，不吃牧场追赶倍率 |
| 累计上限 | 每只牧场怪物最多累计 8 小时挂机收益 |
| UI 反馈 | 牧场槽位显示“专注 / 追赶 x倍率 / 陪伴 +百分比” |

设计边界：

- 牧场追赶不替代出战成长，只帮助落后怪物进入可试用区间。
- 陪伴收益是轻量增益，不产出永久羁绊属性；永久羁绊留给后续 P3 分支系统。
- 8 小时封顶用来控制离线收益膨胀，并制造每日回收节奏。

## 5.6 牧场社交高价值结果

社交高价值结果用来制造长期记忆点，但必须控制频率和代价，避免变成稳定刷资源入口。

| 结果 | 第一版规则 |
|---|---|
| 生育 | 异性、关系达到亲近、相性高于 86 时触发，生成 1 只 Lv.1 复合幼体；极高相性或羁绊同属性可生成 2 只 |
| 侵蚀 | 暗/虚空/混沌或凶猛倾向怪物在低相性边界下触发，一只吞噬另一只 |
| 侵蚀收益 | 吞噬者获得额外经验，但写入 `erosion_hunger` 与负面状态 |
| 结果展示 | 社交领取时通过弹窗展示事件、收益和特殊结果，不再只靠状态文字 |

社交场所第一版时长：

| 场所 | 完成时间 | 设计意图 |
|---|---:|---|
| 草坪庭院 | 1小时 | 低门槛试用、关系入门 |
| 暖阳广场 | 2小时 | 中等节奏，适合高相性和活跃事件 |
| 静水池 | 6小时 | 长线沉淀，适合安定、治愈和高风险深层结果 |

设计边界：

- 生育产物从 Lv.1 开始，价值来自复合血缘和特质，不直接给高等级战力。
- 侵蚀属于高风险结果，下一步需要加入保护/确认或场所风险提示，避免玩家误损失核心怪物。
- 第一版不额外扩大金币和道具奖励口，社交价值主要来自怪物池变化和关系记忆。

## 5.7 地图解锁节奏

地图解锁服务于章节推进，不让玩家一开始直接跳到所有战斗。

| 规则 | 口径 |
|---|---|
| 初始开放 | 只开放 `stage_1_1` |
| 主线推进 | 通关前一主线关后开放下一主线关 |
| 章节推进 | 通关上一章 Boss 后开放下一章第一关 |
| 精英支线 | 通关前一主线关后开放，不阻挡本章 Boss |
| 扫荡 | 仍需该关 3 星通关 |

## 6. 留存结构

## 6.1 短线留存

每 1-3 局给一个小期待：

- 新捕捉目标
- 新棋盘机制
- 新技能体验
- 关卡首通奖励
- 图鉴生态进度

## 6.2 中线留存

每 20-40 分钟给一个中目标：

- Boss 破招
- 进化
- 新构筑成型
- 精英关挑战
- 一组生态收藏完成

## 6.3 长线留存

长线目标不只堆等级：

- 章节怪物生态收集
- 羁绊分支
- 捕捉偏好研究
- 特殊 Boss 队伍解法
- 高星关卡与更优路线

## 7. 星级、奖励、捕捉口径

以下系统必须只有一个公式源：

- 星级评价
- 奖励倍率
- 捕捉概率
- 怪物经验发放
- 扫荡收益

UI 只展示结果，不在展示层另写独立规则。

## 7.1 当前公式源

代码公式源为 `src/battle/reward_rules.gd`。

| 规则 | 第一版口径 |
|---|---|
| 星级评价 | `血量比例 * 0.6 + 回合效率 * 0.4`，达到 0.8 为 3 星，达到 0.5 为 2 星，否则 1 星 |
| 胜利奖励 | 关卡基础奖励 × 星级倍率 |
| 星级倍率 | 1 星 60%，2 星 80%，3 星 100% |
| 失败奖励 | 关卡基础奖励 × 30% |
| 怪物经验 | 与胜利结算经验一致，只发给存活出战怪物 |
| 扫荡收益 | 对应星级胜利奖励 × 80% |
| 保底配置 | 关卡未配置奖励时使用统一默认奖励，避免 UI 和存档出现不同兜底 |

捕捉概率仍由 `src/battle/capture_system.gd` 负责；战斗评价星级已委托给 `RewardRules`，结算页不再拥有独立星级公式。

## 8. 验证方法

## 8.1 必做模拟

每次大调参至少验证：

1. Ch1 首战
2. Ch1 Boss
3. 第一只精英关
4. 第一次锁定宝石关
5. 第一次毒雾关
6. 中后期 Boss

## 8.2 必看指标

- 平均通关回合
- 失败率
- 三星率
- 首次捕捉成功耗时
- 新怪进入队伍耗时
- 首次进化耗时
- 每章节金币净流入
- 捕捉道具消耗率
- 主队元素和角色分布

## 8.3 设计审查问题

每次新增系统前先问：

- 它给玩家新增了什么判断？
- 它和怪物构筑发生了什么联系？
- 它有没有挤压现有系统的价值？
- 它是否能被数值验证，而不只是看起来热闹？
