## 项目结构

- `main.gd`：应用入口和场景路由。
- `src/core/`：存档、场景、成长、进化、牧场社交。
- `src/match3/`：三消棋盘。
- `src/battle/`：战斗、伤害、捕捉、奖励、Boss。
- `src/ui/`：正式 UI 场景和控制器。
- `assets/`：运行时图片、音效、字体。
- `tests/`：Godot 回归和截图辅助脚本。
- `docs/`：设计源、健康报告和归档资料。
