# 待人工确认字段

## 微信后台字段

- 游戏名称最终展示、字数限制和命名合规。
- 游戏简介/一句话简介/详细介绍的字段拆分与字数限制。
- 游戏头像/图标的尺寸、格式、文件大小、透明底和圆角要求。
- 游戏类目、资质、版号、软著、自审报告等是否必填。
- 隐私政策、用户协议、个人信息收集说明是否必须填写及入口形式。
- 审核测试账号是否需要；当前未提供，且项目未检测到登录流程。
- 截图、封面、分享图的后台实际数量、尺寸、格式、大小和是否必填。
- 版本号、版本说明、提审版本名称。
- 微信端运行方向与导出配置。
- 是否需要概率披露：当前存在捕捉概率、掉落、性格随机和游戏内社交结果。
- 游戏内商店的宝石/金币来源是否涉及真实付费；当前未检测到支付 SDK。

## 工程风险

- 采集、正式场景资源检查和 P0 冒烟测试发现的缺失资源引用是否需要先修复；完整列表见 `90_交付报告与追溯/run_report.md`。
- Android 模板 `screenOrientation="landscape"` 与 Godot 项目/实际截图竖屏信号不一致；微信端导出配置需确认。
- 运行时美术和音频资源的正式授权文件未在项目中完整发现。
- 后台所需客服、备案、主体信息等未提供。
