# 审核体验路径

## 推荐审核路径

1. 打开游戏，进入启动页。
   - 预期页面：显示《萌灵消消大冒险》标题、三只主视觉精灵和“进入游戏/开始冒险”按钮。
   - 账号依赖：无。
   - 网络依赖：当前本地构建未检测到网络依赖。

2. 点击“进入游戏/开始冒险”。
   - 预期页面：进入主大厅。
   - 可见入口：开始冒险、商店、精灵旅馆/牧场、精灵课堂、图鉴、背包、成就、设置、签到。

3. 点击“开始冒险”。
   - 预期页面：进入章节关卡地图。
   - 审核重点：确认关卡节点、章节标题、体力/资源显示。

4. 选择第一章第一关或当前已解锁关卡。
   - 预期页面：进入战斗准备页。
   - 审核重点：敌方信息、我方队伍、战力对比、奖励预览和“进入战斗”按钮。

5. 点击“进入战斗”。
   - 预期页面：进入 8x8 三消战斗棋盘。
   - 审核重点：交换宝石、连锁、敌方意图、队伍血量、捕捉球/道具入口。

6. 完成战斗并进入结算。
   - 预期页面：胜利/失败结算或捕捉结果。
   - 审核重点：奖励展示、捕捉结果、确认/查看图鉴按钮。

## 可选补充路径

- 主大厅 → 图鉴：查看精灵图鉴和收集进度。
- 主大厅 → 精灵课堂/牧场：查看成长、进化、牧场放置与游戏内社交系统。
- 主大厅 → 商店：查看游戏内金币/宝石道具商店；当前未检测到真实支付 SDK。
- 主大厅 → 签到/成就：查看日常奖励和成就奖励。
